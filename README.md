## 🚀 Getting Started

Clone the repository and open it locally:

```bash
git clone https://github.com/ashok01thapa/AshokThapa-Portfolio.git
cd AshokThapa-Portfolio
```

Then simply open `index.html` in your browser, or, if the project uses a build tool (e.g. npm-based):

```bash
npm install
npm start
```
